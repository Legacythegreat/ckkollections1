# CK Kollections

A simple PHP storefront with premium champagne-gold inspired styling.

## Setup

1. Run a local PHP server in the project root:
   ```bash
   php -S localhost:8000
   ```
2. Open `http://localhost:8000` in your browser.

## Notes

- The site uses session-based cart state with `$_SESSION`.
- Product data is stored in `includes/functions.php`.
- `public/styles.css` contains the store theme.
